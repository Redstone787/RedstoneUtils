# Privacy and Data

Redstone Utils has no telemetry, analytics, advertising, external update tracker, or automatic crash reporting. It does not send data to the maintainer.

It stores settings, profile keys, macros, server limits, exports, and recovery backups locally in Minecraft's `config` directory. Multiplayer profile keys contain the configured server address; singleplayer profile keys contain the save-directory name. Macro files contain user-entered commands and key bindings.

With a compatible server, gameplay payloads are exchanged only with the currently connected Minecraft server for backend detection, AutoWire, teleport requests, feedback, and client UI actions.

Read the repository's full [PRIVACY.md](https://github.com/Redstone787/RedstoneUtils/blob/main/PRIVACY.md). For a sensitive report, use [private vulnerability reporting](https://github.com/Redstone787/RedstoneUtils/security/advisories/new), not a public issue.
