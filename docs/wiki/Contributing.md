# Contributing

The authoritative contribution rules are in [CONTRIBUTING.md](https://github.com/Redstone787/RedstoneLabworks/blob/main/CONTRIBUTING.md).

In short:

1. Search existing issues and discuss large or breaking changes first.
2. Use JDK 25 and run `./gradlew build`.
3. Add tests and update translations/documentation where applicable.
4. Do not submit secrets, personal data, Minecraft assets, decompiled game code, or material without compatible redistribution rights.
5. Sign every commit under the [Developer Certificate of Origin 1.1](https://github.com/Redstone787/RedstoneLabworks/blob/main/DCO) with `git commit --signoff`.

Contributions to covered source files are accepted under MPL-2.0. Participation is governed by the [Contributor Covenant 2.1](https://github.com/Redstone787/RedstoneLabworks/blob/main/CODE_OF_CONDUCT.md).
