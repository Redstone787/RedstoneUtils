# Support

- Usage and configuration: read the versioned [Wiki source](docs/wiki/Home.md).
- Reproducible bug: use the [bug report form](https://github.com/Redstone787/RedstoneUtils/issues/new?template=bug_report.yml).
- Feature idea: use the [feature request form](https://github.com/Redstone787/RedstoneUtils/issues/new?template=feature_request.yml).
- Security or private data: use [private vulnerability reporting](https://github.com/Redstone787/RedstoneUtils/security/advisories/new), not a public issue.

This is a volunteer project. Support, compatibility, fixes, and response times are not guaranteed.
