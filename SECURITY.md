# Security policy

## Supported versions

| Version | Security fixes |
| --- | --- |
| Latest `2.x` development version | Yes |
| Private prereleases through `1.3.1` | No |

Only the latest maintained version receives security fixes. A public release has not yet been made.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or chat log. Use [GitHub private vulnerability reporting](https://github.com/Redstone787/RedstoneLabworks/security/advisories/new) and include:

- the affected version or commit;
- a minimal reproduction or proof of concept;
- the likely impact and required permissions;
- any suggested mitigation.

Please remove access tokens, personal data, server addresses, and private world data from reports. Receipt and severity will be assessed as time permits; no fixed response or disclosure deadline is promised. Coordinated disclosure is appreciated.
